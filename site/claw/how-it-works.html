CLAWERN

How It Works.

A visual guide to the architecture of an autonomous law firm that runs on a Mac Mini.

Pattern 1

The Basic Loop

At its core, Clawern watches a folder. When a new document appears, it runs the full Lavern multi-agent pipeline — debate, verification, assembly — and delivers results. No human interaction needed.

# That's it. Two commands.
lavern claw init
lavern claw start
# Drop files. Walk away.
Pattern 2

The Intelligence Loop

Every document Clawern reviews makes it smarter. Significant findings are indexed into a Precedent Board — persistent institutional memory. Before processing future documents, matching precedents are injected as context.

Key insight: The firm gets smarter with every document. A liability cap pattern found in an NDA in January informs the review of a different NDA in March — automatically, with no human intervention.
Pattern 3

The Confidentiality Gate

Documents matching sensitivity patterns (*confidential*, *privileged*, *merger*) are analyzed entirely on-device via local models. Data never leaves the machine. Zero cost.

Pattern 4

The Notification Web

A real law firm calls you when something matters. Clawern pushes critical findings to every channel you use — Telegram, email, webhook, macOS notifications. You don't check the dashboard; the dashboard checks you.

The Full Picture

Everything Together.

Clawern is not a single agent. It's an orchestrated system: a file watcher, a planner, a processor (which dispatches 65 agents), a delivery engine, an institutional memory, an audit trail, a notification web, and a voice interface — all running autonomously on your hardware.

Autonomous Processing
Watches folders, parses documents (PDF, DOCX, MD), infers workflow, dispatches agents, delivers results. Budget-aware, sensitivity-aware.
Institutional Memory
Precedent Board indexes findings across engagements. Evidence-linked, confidence-decaying, relevance-scored. The firm remembers.
Change Detection
When a document changes, Clawern compares new findings to the previous review: "+3 new, -1 resolved, ~2 changed." Re-reviews actually tell you what's different.
Voice Dispatch
"What's the status?" from your phone. Web Speech API input, keyword routing (no LLM cost), spoken response. The firm in your pocket.
Cost Transparency
Forecast before processing. Budget gauges. Cost per document. Per-agent breakdown. Confidential docs are always $0 (local model). Never a surprise bill.
Production Hardened
1,392 tests. Audit trail. Daily backups. Prometheus metrics. Path traversal defense. Notification redaction. The firm doesn't crash.
